## 2. Merge Feature: Why It’s Needed (Review Only)

- **What the tool creates:** `KeywordExtraction` writes one `*_keywords.csv` per text file (columns `keyword`, `count`). Classification (e.g. `classify_specific`) was explicitly out of scope for this session.
- **Gap:** There was no way to combine multiple keyword CSVs into a single corpus-level file with aggregated counts.
- **Goal of merge:** Take one or more `*_keywords.csv` files, sum `count` per `keyword`, and write one CSV with columns `keyword`, `count` (optionally top-N and sort).

## 5. Implementation of `merge_keyphrase_csvs`

- **File:** `txt2phrases/merge.py`

**Behaviour:**

- **`_resolve_input_paths(input_paths)`:** If single `Path` and directory → `sorted(path.glob("*.csv"))`; if file → `[path]`. If list → use as-is; empty list → `ValueError("No files to merge: input_paths is empty")`.
- **`_read_and_validate_csv(path)`:** Read CSV; require columns `keyword`, `count`; raise `ValueError` with missing column name(s) if not present; return DataFrame with only those columns.
- **`merge_keyphrase_csvs(...)`:** Resolve paths → read and validate each CSV → concatenate → `groupby("keyword")["count"].sum()` (int) → sort by count descending (default) or keyword ascending → optional `top_n` → write CSV. Creates output directory if needed.

**Result:** All 11 Phase A tests pass.
